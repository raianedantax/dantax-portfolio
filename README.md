# Cyberpunk Portfolio - React Version

Uma versão simplificada do portfolio cyberpunk criada com React e JavaScript puro.

## 🚀 Tecnologias

- React 18
- JavaScript (ES6+)
- Vite
- Lucide React (ícones)
- CSS3 com variáveis customizadas

## 🎨 Características

- Design cyberpunk com efeitos neon
- Animações CSS puras
- Layout responsivo
- Navegação suave entre seções
- Formulário de contato funcional
- Componentes modulares

## 📦 Instalação

1. Clone o repositório:

```bash
git clone <url-do-repositorio>
cd cyberpunk-portfolio-react
```

2. Instale as dependências:

```bash
npm install
```

3. Execute o projeto:

```bash
npm run dev
```

4. Abra no navegador:

```
http://localhost:5173
```

## 🎯 Seções

- **Hero**: Apresentação principal com animações
- **About**: Informações sobre habilidades e experiência
- **Projects**: Portfolio de projetos
- **Contact**: Formulário de contato
- **Footer**: Links sociais e informações

## 📱 Responsividade

O projeto é totalmente responsivo e funciona em:

- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)

## 🔧 Personalização

Para personalizar o portfolio:

1. **Cores**: Edite as variáveis CSS em `src/styles/index.css`
2. **Conteúdo**: Modifique os textos nos componentes
3. **Projetos**: Atualize o array `projects` em `Projects.jsx`
4. **Contato**: Configure o formulário em `Contact.jsx`
